# 中、長期對話包（emotion-trend）

情緒分析面板的「中、長期對話」分頁。依《情緒變化介面重新設計需求書（中、長期對話）》實作。

## 兩包的結構

```
components/
├─ emotion-panel/    外殼：拖曳寬度、標題、分頁切換、錯誤邊界（不放圖表邏輯）
├─ emotion-single/   單一對話包（樣式沿用 styles/app.css 的 .ec-*）
└─ emotion-trend/    中、長期對話包（本資料夾）
```

- 外殼用 `import.meta.glob("../emotion-*/index.js")` 自動載入分頁包；移走任一包的資料夾，另一包仍能編譯與顯示。
- 兩包互不 import；共用的只有唯讀的 `history`（本包只取 `analyzedAt` 與 `score`）和專案全域色票。
- 每包各自包一層錯誤邊界：一邊出錯不會讓另一邊或聊天畫面跟著白畫面。

## 本資料夾的檔案

| 檔案 | 內容 |
|---|---|
| `index.js` | 分頁註冊（key、標籤、排序、元件），載入本包樣式 |
| `TrendView.jsx` | 分頁本體：頂部摘要、「?」使用說明、兩張圖 |
| `TrendCharts.jsx` | K 線圖 + 長條圖的外框：同步左右拖曳、跟著最新、「回到現在」、提示框 |
| `CandleChart.jsx` | 中期 K 線圖（SVG） |
| `RangeBars.jsx` | 長期長條圖（SVG） |
| `Guide.jsx` | 3 步導覽（localStorage 記錄已看過） |
| `calc.js` | 純計算：切格子、`calcChange()`、狀態詞、摘要、Y 軸範圍 |
| `useNow.js` | 目前時間（定時檢查 + 回到前景時更新） |
| `constants.js` | 可調參數：`CELL_MINUTES`、`BAR_MINUTES`、`LARGE_CHANGE_THRESHOLD`… |
| `emotionTrendCopy.js` | 所有文字 |
| `emotion-trend.css` | 本包樣式（`.et-*`） |
| `fixtures.js` | 測試用假資料（只在開發模式） |

## 目前的設定值

| 項目 | 值 | 位置 |
|---|---|---|
| K 線每格 | 5 分鐘，對齊時鐘 | `CELL_MINUTES` |
| 長條每根 | 10 分鐘 | `BAR_MINUTES` |
| 一次顯示 | 12 格（1 小時） | `WINDOW_CELLS` |
| 紅色門檻 | 變化量 ≥ 20 | `LARGE_CHANGE_THRESHOLD` |
| K 線 Y 軸 | 0–100，資料超出時自動延伸（負數完整畫出，並畫 0 線） | `SCORE_MIN` / `SCORE_MAX` |
| 狀態詞 | ≤20 很負面、≤40 偏負面、<60 中性、<80 偏正面、≥80 很正面 | `STATUS_CUTS` |
| 目前綜合分數 | 進行中這一格的平均；這一格還沒有訊息時用最近一筆 | `calc.js` `buildSummary` |
| 趨勢句 | 和 10–20 分鐘前的平均相比，差距 < 5 算差不多；那段沒資料時改和 30 分鐘內、10 分鐘以前最近的一筆比 | `TREND_SAME_RANGE` |
| 計時起點 | 進入頁面時；重新整理後從最早一則訊息所在的格子補回 | `TrendView.jsx` `ENTERED_AT` |
| 時間來源 | 情緒紀錄的 `analyzed_at` | `calc.js` `toPoints` |
| 長條 Y 軸 | 自動隨最大變化量調整 | `calc.js` `changeDomain` |
| K 線顏色 | 色票紫色 `--sp-lilac-500`（不隨主題色變，避免變成紅色） | `emotion-trend.css` |

## 測試用假資料

`npm run dev` 後在網址加上 `?trendDemo=<名稱>`，例如 `http://localhost:5173/?trendDemo=many`。
登入後打開情緒面板，切到「中、長期對話」，摘要下方會顯示「測試資料：<名稱>」。正式打包（`npm run build`）不會啟用。

| 名稱 | 情境 |
|---|---|
| `empty` | 空資料 |
| `one` | 只有 1 則 |
| `negative` | 有負分數（含 -38、-27） |
| `gaps` | 中間有空格 |
| `idle` | 很久沒對話（最後一則在 2 小時前） |
| `many` | 大量訊息（最近 3 小時、每分鐘 1–3 則，給老師 Demo） |

## 手動測試步驟（對照驗收標準）

1. **單一對話不受影響**：切到「單一對話」，畫面和行為與改版前相同（點折線圖的點會跳到訊息、滾輪縮放、雷達圖與卡片）。
2. **兩包獨立**：把 `emotion-trend/` 暫時移出 `src/components/`，執行 `npm run build` 與 `npm run dev`，單一對話仍正常；放回後改移 `emotion-single/`，中、長期仍正常。測完記得放回。
3. **沒有六大情緒**：中、長期分頁沒有六情緒的圖、卡片、圖例，也沒有圖表種類切換。
4. **K 線方框**：用 `?trendDemo=many`，每格是直角方框，有最高（頂）、最低（底）與平均（中間橫線）；只有 1 則的格子是一條橫線。
5. **時間會走**：不傳訊息等 5 分鐘（跨過 :00、:05…），右邊自動新增一格空白格；把瀏覽器分頁切到背景再回來，錯過的格子會補齊。
6. **長條圖**：每 10 分鐘一根、和 K 線格子對齊；變化量 ≥ 20 為紅色、其餘灰色；長條沒有圓角。
7. **提示框**：滑鼠移上長條，提示框包含變化量的定義；移上方框顯示時間範圍、最高、最低、平均、則數；移上空白格顯示「這5分鐘沒有訊息」。手機改用點擊。
8. **負分數**：用 `?trendDemo=negative`，負數完整畫出，有 0 線，不會被切掉。
9. **導覽**：清除 localStorage（或用無痕視窗）第一次切到中、長期分頁會出現 3 步導覽，看完不再自動出現；按右上角「?」可重開。
10. **拖曳**：在圖上左右拖曳，兩張圖同步移動，出現「回到現在」；按下後回到最新並自動跟著新格子。
11. **重新整理**：有對話紀錄時重新整理頁面，圖依訊息時間重建，空白格也補回。
12. **5 秒測試**：找 2–3 位沒看過的人，先看導覽再看畫面 5 秒，能說出「這是心情隨時間的變化」。

## 之後可以調整的地方

- 紅色門檻：用真實對話算出所有 10 分鐘的變化量，取分布前 20%–25% 的位置當門檻，改 `LARGE_CHANGE_THRESHOLD`。
- 起伏定義：只要改 `calc.js` 的 `calcChange()`（例如換成 RMSSD）。
- K 線顏色：改 `emotion-trend.css` 的 `.et-candle-*`。
